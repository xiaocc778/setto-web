## 7. 图片使用注意事项

### 版权说明
- Unsplash、Pexels、Pixabay 的图片均免费商用
- 部分图库（如Vecteezy）有付费/免费分区，下载时注意
- 建议保存图片来源链接，备查

### 图片规格建议
| 用途 | 最小尺寸 | 推荐尺寸 |
|------|----------|----------|
| Hero背景 | 1920×1080 | 2560×1440 |
| 场景图 | 1200×800 | 1920×1280 |
| 产品特写 | 800×600 | 1200×900 |
| 缩略图 | 400×300 | 600×400 |

### 图片格式
- 推荐使用 **WebP** 格式（体积小、画质好）
- 次选 **JPEG**（兼容性好）
- 背景图建议加 `?w=1920&q=80` 参数压缩

## 8. 产品实拍建议

### 需要自己拍摄的内容
1. **产品包装**：正反面、侧面、细节
2. **挤出效果**：不同角度的胶条形状
3. **施工演示**：涂抹、铺设、压实过程
4. **完工效果**：实际铺设的木地板

### 手机拍摄建议
- 光线充足但避免直射
- 使用微距模式拍细节
- 多角度拍摄
- 背景干净整洁
